SMS Spam Detection Using Deep Learning

Project Description

This project uses TensorFlow/Keras to classify SMS messages as Spam or Ham (legitimate).

Problem Statement

Unwanted and potentially fraudulent SMS messages can expose users to scams, misleading offers, and suspicious links.

Proposed Solution

A Deep Learning model learns patterns from labeled SMS messages and predicts their categories. An additional rule-based checker flags URLs and selected urgency-related phrases.

Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

Key Features

- SMS spam classification
- Model evaluation
- Custom SMS testing
- Suspicious-content warnings

How to Run

Open the ".ipynb" notebook in Google Colab and execute the cells in order. Upload the required dataset when prompted.
